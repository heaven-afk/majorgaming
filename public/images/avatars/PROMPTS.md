# MGL — community character avatars

Four separate square portraits generated in parallel using the built-in image-generation tool on 27 October 2026. Style and identity reference: `../hero-concepts/06-portrait-squad-front.png`. Originals are PNG, web-ready versions are 256px square WebP, suitable for circular CSS crops. These are character illustrations for a community avatar stack.
